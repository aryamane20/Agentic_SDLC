# outputs/p3/agent-runs/

Individual agent prompt test outputs — gitignored.

Generated by: `python scripts/test_p3_prompts.py --agent <name> --tc <tc-id>`

Filename format: `{agent}_{tc_id}_{timestamp}.json`

Each file contains:
- `agent`: agent name
- `tc`: test case id
- `artifact`: the raw parsed output from the agent
- `tokens`: input/output/cache token counts
- `parse_failed`: bool
- `attempts`: number of LLM calls made
- `elapsed_seconds`: wall-clock time
